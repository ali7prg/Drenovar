# DRENOVAR — работа в ветке Codex

Перед изменениями обнови сведения о `origin/codex/drenovar-continuation-2026-11-15` и убедись, что работа начинается с актуального коммита этой ветки. Используй эту ветку. При конфликте сохраняй чужие изменения и не отправляй ветку с принудительной перезаписью истории.

Для задачи, в которой владелец попросил внести изменения в репозиторий:

1. Внеси изменения по задаче и запусти применимые проверки.
2. Проверь список файлов в коммите. Сохраняй только правки задачи. Не включай секреты, сессии, выгрузки базы или данные игроков.
3. Создай коммит и отправь его в эту ветку на GitHub без отдельного напоминания. Проверь, что коммит доступен в удалённой ветке. Повтори для каждого затронутого репозитория.
4. В итоговом сообщении дай ссылки на отправленные коммиты и результаты проверок. Если проверки или отправка заблокированы, укажи причину и статус.

Запросы на чтение, анализ и обсуждение сами по себе не требуют коммита. Если владелец явно попросил оставить правки локальными, следуй его просьбе. Слияние веток и выкладка на Cloudflare выполняются по отдельному запросу.

Проверяй затронутые сценарии Godot. Если владелец запросил тестовый IPA, назначь новый номер сборки и используй `.github/workflows/ios-repack.yml`.
