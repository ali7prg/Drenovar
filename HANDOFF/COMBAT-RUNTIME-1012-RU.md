Скачанный IPA проверен; PCK извлечён из него. 21 модель войск и 162 здания загрузились, главная сцена main.tscn. Две последовательные охоты на Тенерисов I и II с 45 бойцами из этого PCK, реальная тестовая авторизация/HTTP, два 503 после принятия первой команды: 45/45 проверок, Attack в обоих боях, без повторного войска, Continue и повторный вход. 10 боёв исходного кода дали 197/197 проверок. Проверки скачанного пакета — `runtime-1012/`; полные до/после, кадры и видео — `godot/runtime-audit-1012/`.

Подтверждённые причины отсутствия анимации: сервер e5062aa удалял завершённый battle между опросами; клиент сохранял пустой кэш событий подхода и не перестраивал его при переходе к бою. Исправлены в паре клиент+сервер. HTTP 503 теперь отделён от отказа транспорта; HTML-ошибка сохраняет status для ограниченного повтора с прежним receipt.

Ресурсная ошибка НЕ закрыта. Локальное ускорение маршрута Тенериса II 83.64 → 9.69 мс, но расширенная матрица даёт максимум 67.69 мс, реальные патрули — до 15.51 мс. Это Node/Linux, не CPU Cloudflare. Staging-домен заблокирован текущей средой; владелец добавил его в сохранённую среду для следующего запуска и попросил передать коммит. Основной Worker по read-only настройкам Cloudflare остаётся e5062aa; парное серверное обновление не выполнено. Прямой финальный запрос /__health вернул 403, поэтому повторная аттестация сделана через API настроек, а не выдана за успешное соединение приложения.

Одна установка 1012 не закрывает короткие бои без серверного обновления. Данные реальных поселений не менялись. 67/67 исходов и 216/216 путей совпали. Платный CPU не включался. Для production нужно отдельное разрешение владельца после staging. Физический iPhone 12/Metal и Safari не проверены; тестовые видео сделаны на Linux/llvmpipe (OpenGL), качество ресурсов и production-рендерер сохранены.
