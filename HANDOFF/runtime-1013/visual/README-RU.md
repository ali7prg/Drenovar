# Кадры до/после: узкий берег, 200 пеших бойцов

Источник «до» — игровой пакет опубликованной сборки 1012; «после» — пакет, извлечённый из скачанного IPA 1013. Использованы одинаковые 77 записанных авторитетных событий, тот же маршрут, положение Тенериса II, геометрия синтетического города и камера. SHA-256 пакетов, fixture и каждого кадра — в `method.json`.

Симуляция шагала по 40 мс; кадры отрисованы при t=0, 240, 480 и 720 мс относительно начала боя. Сборка1012 не включает Attack у показанных участников. Сборка1013 включает Attack у ENG-02_0 и ENG-02_5; это видно на кадрах480/720 и подтверждено метаданными в `frames.json`. Кадры показывают реальные игровые модели из соответствующего PCK, а не схемы движения.

Это диагностическая последовательность Linux/Godot4.6.3,1366×630, программный OpenGL llvmpipe. Она не является записью непрерывной игры или проверкой FPS/iPhone12/Metal/Safari. Обычный HUD скрыт только внешним скриптом, поверх добавлены подписи текущих clip/ID. Модели, анимации и ресурсы не редактировались. Неподдерживаемые ETC2-текстуры драйвер преобразовал в RGBA8; звук недоступен (dummy). В опубликованном приложении рендерер и качество ресурсов сохранены.

Для начального состояния использовался исключительно отдельный локальный сервер с памятью SQLite; ни staging, ни production, ни endpoint изменения QA-часов не вызывались. `capture-bank.gd` — точный скрипт этого рендера. Каталоги `profile-before`/`profile-after` в рабочей папке не являются частью передаваемых доказательств и не должны копироваться.
