# DRENOVAR — «Лес потерянных»

Версия комплекта **1.1.0 — открытие леса на ратуше III**. Это новая версия по окончательной идее пользователя. Она заменяет прежние концепции «Память воды» и «Последний обоз» для данной задачи. Старые ZIP к этому набору не примешивать.

До завершённого третьего уровня ратуши вокруг поселения виден красивый анимированный туман и текст «Достигните 3-го уровня ратуши, чтобы открыть приключение». После подтверждённого сервером уровня III — однократное плавное вступление с Искрой, объяснением спасения людей и кнопками «Следовать за лошадью» / «Пропустить». Подробности: `docs/HALL3_UNLOCK_AND_INTRO_RU.md`, данные `data/unlock-intro.json`. Новая картинка — `art/18_hall3_unlock_intro.png` в дополнительном пакете07_UnlockArt. Это визуальный ориентир, не готовая анимация.

Если ранее скачана версия1.0.0, замените пакеты00_Start,01_Concept,06_Code и оба внешних JSON. Добавьте07_UnlockArt. Пакеты02–05 не менялись: их можно использовать повторно после проверки новым индексом. Старую распакованную папку не смешивать с новой; распакуйте текущий набор в пустую папку.

Сначала передайте разработчику пакет00_Start и DELIVERY_INDEX.json, затем остальные ZIP в числовом порядке. Все части независимы и распаковываются в общий `DRENOVAR_Forest_Rescue/` без пересечений путей. Главный документ — CLAUDE_CODE_IMPLEMENTATION_BRIEF_RU.md; понятное описание идеи — docs/CONCEPT_RU.md.

Состав:18созданных художественных PNG-референсов; исходные промпты; полная карта/атлас;12мест×5заданий;36жителей; отдельный новый динозавр-босс; большие награды; тексты; данные сохранения; самостоятельная протестированная логика/туман/резерв наград/профилировщик;60спецификаций клипов;8синтетических звуков с исходниками. Точное наличие файлов и статусы — ASSET_REGISTRY.csv и PACKAGE_MANIFEST.json.

По последнему прямому указанию пользователя итоговые3D-модели, риги и анимационные клипы создаёт Claude Code на основе переданных изображений и спецификаций. Их нет внутри PNG и они не объявляются поставленными. Самостоятельные модули не подключены к действующему проекту. Производительность устройства и исправление лагов ещё не проверены.

После скачивания всех файлов в одну папку распакуйте Start во временную папку, перейдите в его DRENOVAR_Forest_Rescue и выполните:

```sh
python3 tools/verify_delivery.py /absolute/path/to/downloaded_packages --extract /absolute/path/to/new_empty_folder
```

Скрипт проверит точные размеры≤30_000_000байт, SHA-256, ZIP CRC, зависимости, безопасность/уникальность путей и распакованные байты. Склейка не нужна: разделённых файлов нет. Внешний DELIVERY_INDEX.json содержит размеры/хеши ВСЕХ ZIP, включая Start. Внутренний PACKAGE_MANIFEST не может содержать собственный хеш стартового ZIP; его целостность покрывает внешний индекс. Проверочный отчёт DELIVERY_VERIFICATION.json передан отдельно, чтобы проверка не меняла проверяемый архив.

Порядок чтения: концепция → карта/туман → художественное производство → сценарии/экономика → код/сохранения → анимации/производительность → полное инженерное распоряжение. Не используйте числа из старых наборов: актуальные результаты и ограничения смотрите в qa/READINESS_RU.md и фактических логах текущего комплекта.

Сообщение Claude Code:

> Получи все пакеты DRENOVAR Forest Rescue и DELIVERY_INDEX.json. Прочитай START_HERE_RU.md и CLAUDE_CODE_IMPLEMENTATION_BRIEF_RU.md, проверь целостность. Реализуй «Лес потерянных» в существующем DRENOVAR: новый лес на всей внешней карте, лошадь-проводник, доступ только с завершённого уровня ратуши III, анимированный туман до открытия, однократное вступление и постоянное раскрытие тумана,12мест/60заданий/36спасённых, крупные серверные награды и финальный динозавр-босс. Создай настоящие3D, риги и плавные анимации по изображениям и спецификациям, подключи проверенные модули к реальным системам. Сохрани базу, собственность и прогресс игроков. Доведи до работающего результата с реальными проверками iPhone12; не останавливайся на плане. При недостающем доступе/пакете назови его точно и продолжай независимые задачи. Не заявляй выполненные проверки без их проведения.
