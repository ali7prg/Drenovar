# Производство моделей, ригов и естественных анимаций

Кампания `forest_rescue_v1`:12 мест спасения, по3 пленника, гнедая лошадь-проводник без всадника, сопровождающие солдаты, Тенерисы и финальный динозавр `ancient_maw` / `lf_boss_ancient_maw`. Этот документ и `data/animation_manifest.json` — **задание на производство и интеграцию**, не файлы готовых анимаций. Изображения в комплекте служат визуальными ориентирами. Они не являются3D-моделями, skinning, motion capture, walk cycles или клипами GLB. Новые готовые персонажные риги/анимации здесь не заявлены.

Пользователь выбрал цепочку изображения → моделирование Claude Code. Поэтому Claude Code должен по этим изображениям произвести реальные editable модели, топологию, UV, материалы, skeleton, weights, клипы и игровые версии; проверить их в существующем DRENOVAR. Если доступного инструмента для качественного персонажного производства нет, это обязательная незавершённая часть, а не повод показать капсулу вместо человека или назвать покачивающийся rigid mesh естественной походкой.

## Источники и совместимость

Проверенная база: `DRENOVAR-Server-v92/` внутри репозитория `ali7prg/drenovar-server`, HEAD `56dce339b8adf527244c5d59fdc64a0f701ac64b`. Подробности проверки в `docs/PERFORMANCE_AUDIT_RU.md`.

- `dist/army/spearman-actor.js:15–32`: `SpearmanActor`, `cloneRig`, `AnimationMixer`, `setActivity`, `present59`, `setLOD`. `present59` ведёт walk по пройденному расстоянию, strike по серверному времени. Реальная `stepTime59` находится в `dist/creatures37/motion59.js:10`; текущие stride1.25 / mounted3.6 относятся к старым моделям, не копируются как универсальная длина шага новых персонажей.
- `dist/army/unit-visuals.js`: ENG-05 scout и ENG-06 knight имеют `mounted:true`, `Attack`, `Mounted_Drill`; у пехоты существующие `Sword_Drill`, `Spear_Drill`, `Bow_Draw` и другие. Названия в новом манифесте с `lf_` — **новые предлагаемые клипы**, не уже существующие API/ассеты.
- `dist/creatures37/actor.js:10–15`: `CreatureActor` работает с Idle, Walk, Alert, Attack, Hit, Roar, Death; названия поддержаны кодом, однако отсутствие480 оригинальных графических файлов не позволяет утверждать, что исходные Тенерис-клипы просмотрены и качественны. Восстановить настоящий GLB, не генерировать подмену исходнику по одному имени. `gameplay37/server/catalog.mjs` отмечает эти ресурсы как `animated_v2_prototype_art_pending`: восстановление байтов не является художественной приёмкой естественности.
- `dist/creatures37/motion59.js`: `PresentationClock59` сглаживает поздние snapshots, избегая обратных скачков. Не заменить его прямым `Date.now()` в каждом NPC.
- `dist/runtime/assets.js` и `gltf-retention28.js`: использовать общую загрузку, animation extras копируются в `clip.userData`, большой parser.json очищается. Не читать motion metadata только из удалённого parser.json.
- Существующий бой рассчитывается сервером. Новые `attack_scheduled`, `attack_resolved`, `phase_changed`, `boss_defeated` — предложенный контракт кампании, который необходимо реализовать/сопоставить с её кодом; не выдавать их за готовые события v92.

Существа velkor/kamneklyk/dragor на поздних площадках используют восстановленные оригинальные rigs/клипы через тот же CreatureActor. Они не объявляются произведёнными этим набором. Перед выпуском проверить Idle/Walk/Alert/Attack/Hit/Death каждого требуемого уровня и оригинальные специфические атаки, включая рога, бивни и ударную волну; при дефекте доработать настоящий исходник, не заменять видом Тенериса.

## Обязательные результаты производства

На каждого нового персонажа: editable source (например `.blend`), mesh с чистой deform-топологией, UV без случайных разрывов на видимых местах, материал/карты, rig в понятной rest pose, skin weights, клипы, LOD-экспорты, метаданные strides/contact markers/bounds, видео проверки с пола и игровой камеры. Исходное качество не урезать ради30MB передачи; крупный исходник делить без потерь с проверкой восстановления.

glTF2.0: +Y вверх, предлагаемый +Z вперёд, масштабы применены, root на земле, единицы метр; адаптер должен сопоставить это с реальным масштабом карты. Нельзя неконтролируемо менять scale после расчёта скорости/stride/collision. Экспортировать mesh, skeleton и анимации согласованно; не оставлять незапечённые Blender constraints как единственный источник движения.

Гуманоидам edge loops вокруг плеча/локтя/таза/колена/лодыжки; никаких rigid цилиндров вместо сгибающихся конечностей. Максимум4 skin influences на vertex в игровых копиях, веса нормализованы; удалить пустые deformer bones, но сохранить нужную форму сустава. Руки не срастаются с оружием, стопы — с землёй. Нужны отдельные sockets для оружия/проводья/фонаря. Facial blend shapes умеренные; только там, где видна мимика в close shot, а не десятки morphs на каждом далёком NPC.

Канон по `art/horse_guide_turnaround_motion.png`: гнедая лошадь, тёмные грива/хвост, белая звёздочка на лбу, потёртый недоуздок с зелёной лентой. Всадника, седла и стремян нет. Лента — отдельная прикреплённая деталь с ограниченным secondary motion, без самопересечений. Для дикого зверя и босса отдельный анатомический rig: хвост с плавным распределением кривизны, jaw hinge, шея/грудь/таз, пальцы/когти только по визуальной необходимости. Большого босса нельзя получить простым увеличением обычного Тенериса: новая масса, пропорции, сопротивление повороту и силуэт. Если sheet задаёт ориентир8m, это масштаб для производства нового существа, не измерение текущей сцены; перед фиксацией проверить полный размах хвоста/атаки, арену, камеру и перевод метров в world units.

## Качество движения

**Проводник.** Шаг лошади четырёхтактный; рысь — диагональные пары с корректной фазой опоры. На лошади нет человека и седла; движение зелёной ленты и взгляд назад поддерживают пролог. Stop clip переносит вес, а не мгновенно выключает walk. На маленьком радиусе поворота использовать authored turn, не вращать весь скользящий корпус на месте. Поворот головы назад и короткий зов помогают вести отряд; не приписывать лошади человеческие жесты.

**Солдаты.** Различимые idle/guard/walk/jog; шаг управляется скоростью маршрута и длиной authored stride. Оружие имеет вес, recovery после удара; hit не проигрывается всем одновременно без server event. Обход вокруг проводника и клеток не пересекает союзников. В строю небольшая фиксированная разница phase по ID, а не случайность каждый кадр.

**Пленники.** Три authored idle-варианта: сидящий, стоящий, ожидающий; дыхание/взгляд/перенос веса, без карикатурного синхронного трясения всех фигур. После открытия: реакция → подъём при необходимости → выход через реальную дверь → движение по маршруту сопровождения → прибытие/благодарность. Стопа не проскакивает через прутья; друг за другом выходят с небольшим визуальным offset, серверное состояние спасения не зависит от длины этой очереди. Уставший follow имеет другой силуэт и cadence, без преувеличения боли.

**Тенерис.** Настороженность читается до атаки, перенос массы и постановка лап до резкого выпада. Death заканчивается устойчивой позой. Уровень/элитность различать материалом/силуэтом/масштабом в допустимых пределах; не ускорять все кости вдвое ради сложности. Восстановленный оригинальный rig сначала просмотреть, затем ретаргетировать или доработать с сохранением исходника.

**Босс.** Медленный перевод веса перед мощным движением, неподвижная опорная стопа в первой фазе, хвост следует телу с запаздыванием. Telegraph читается silhouette+ground zone+звук/текст, не только цвет. Фазовый roar не должен телепортировать root или случайно наносить урон. Большой хвост проверять по swept bounds на здания/стены/камеру. При смерти тело не должно провалиться в землю или перекрыть обязательный путь выхода без решения.

## Контакт с землёй и серверный маршрут

Root перемещается только по авторитетному маршруту и его presentation interpolation. Игровые locomotion-клипы **in place**, без второй скрытой root translation. Пройденное расстояние определяет phase цикла; изменение скорости допускает blend walk/jog или walk/trot с согласованием foot phase. Бесконтрольное изменение timeScale для исправления скольжения запрещено. Production metadata хранит реальную длину stride каждого клипа, а не число, подобранное без просмотра.

Near LOD: foot/hoof contacts + terrain alignment/IK в пределах ankle/leg reach; pelvis компенсирует небольшой перепад. Минимум две ноги не теряют землю одновременно в обычном человеческом шаге. При большом перепаде исправить route/navmesh, не растягивать конечность. При выбранном масштабе ориентир max видимого скольжения опорной стопы2cm за опорную фазу; уточнить после просмотра на игровой камере. Для дальнего LOD допустимо отключить IK, сохранив ground root и stride.

Root yaw сглаживается к tangent маршрута; sudden reversal требует turn/stop, а не рывок180°. Существующий `turnTowards` из `dist/creatures37/march38.js:8` — реальная функция сглаживания угла; она не заменяет постановку turn clip и ограничение кривизны маршрута.

После background/reload восстановить корректные stage, pose и event phase из подтверждённого state/server time; не воспроизводить заново death/reward/release. Продвижение escort, освобождение и награды не должны зависеть от FPS, видимости, `AnimationMixer.finished` или аудио callback.

## Лес, туман, клетки и механизмы

Деревья: общий медленный trunk bend, secondary branch sway, высокочастотный leaf flutter с общей направленностью ветра. Не качать всю модель rigid вокруг центра. Маска веса у корня0; ствол не скользит по земле. Phase из стабильного instance seed, ветер плавно меняется по времени. Shader deformation обязана расширять bounds, иначе дерево исчезает на границе кадра. Дальние LOD сохраняют средний силуэт и ветер без резких переключений.

Туман: исследованная территория — серверный прогресс, визуальная маска плавно открывается примерно2s. Во время blend уже подтверждённые цели доступны по правилам кампании; нельзя каждый кадр пересчитывать всю карту открытий и отправлять её в сеть. Использовать локальные обновляемые mask tiles/чанки, ограничить прозрачный overdraw. При Reduce Motion короткий fade, без внезапного прыжка камеры и вспышек.

Клетка: сначала latch освобождается, потом gate начинает открываться, проход становится видимым до выхода первого пленника. Door pivot совпадает с петлёй, ноги не пересекают коллизию. Серверный unlock принимается один раз; повтор сетевого ответа не закрывает дверь и не перезапускает освобождение. Rope/lock/banner клипы включены как механические targets. Сами законченные модели этих механизмов и их клипы ещё надо произвести по image sheets.

## LOD и множество живых персонажей

Числа костей/треугольников в манифесте — верхние стартовые targets для production, не замеры уже готовых meshes. Сохранять высококачественный source отдельно. Для каждого LOD retain silhouette, joints, sockets и имена действий. Retarget/LOD переход сохраняет normalized gait phase, выбранную activity и authoritative root. Переход с hysteresis/dither по возможностям текущего renderer; нельзя стробить mesh при каждом zoom-пикселе.

На близком плане полноценные skinning и естественные контакты; средний план может sampling позы15–30Hz с interpolation, дальний — проверенные authored impostors/запечённые варианты. Нельзя использовать кадр из concept sheet как готовый animation atlas. Не показывать собранную в одном месте36-персонажную толпу, если её исходный layout, collisions и budget не продуманы: сформировать несколько осмысленных групп и маршрутов, сохранив всех людей в состоянии мира.

Глобальный budget actor updates общий с армиями и охотой; новых24 near-актора в performance doc — лишь исходная цель. Список видимых/активных обновлять через spatial cells и события, не обходить каждый скелет/все деревья мира на каждом frame. Отключение offscreen mixers не останавливает серверный escort. Не создавать `new AnimationMixer` каждый tick и не повторять GLB decode при каждом состоянии.

## Приёмка естественности

Проверить отдельно flat terrain, склон, остановку/разворот, медленную/быструю скорость, путь возле клетки, людей в тесной группе, background/resume и смену LOD. Видео для каждой locomotion: сбоку на уровне ног, спереди, сверху и из реальной игровой камеры; минимум3 полных цикла. Frame-step contact markers, нет рывка между последним/первым кадром, непрерывные quaternions, без отрицательного scale на deform цепи.

Прогнать full rescue: видимый пленник внутри → взаимодействие → дверь → выход3 людей → сопровождение → прибытие; затем boss3phases, все attacks, death и reload completed. Проверить одинаковый исход на30/60fps, mute и Reduce Motion. Для лошади одновременно смотреть копыта, шею, грудь, недоуздок и зелёную ленту. Для босса — силуэт телеграфа на дальней камере и отсутствие незаметного damage до active window.

Отчёт обязан включать реальные файл/clip names, bone/vertex/triangle counts, skin weights max, draw calls, размер decoded textures, animation bounds, список проигранных клипов и device timings. Нарисованная раскадровка не засчитывается как проверка движения.

Готово в текущей передаче: спецификация,60 записей clip manifest, source-code audit, тестируемый profiler. Требуется произвести и проверить: новые модели/риги/weights/клипы, production LOD, ретаргет старых восстановленных ассетов, runtime adapter, серверные события, Browser/iPhone12 художественный и performance QA. Комплект не объявляется полноценным уже готовым персонажным asset pack.

Производительность и естественность проверить в живой сцене.
