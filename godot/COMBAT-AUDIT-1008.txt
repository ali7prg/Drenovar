ИЗМЕНЕНИЯ И СТАТУСЫ
D01 — подтверждён, частично исправлен в Godot; iPhone и веб-оружие OPEN.
Сервер добавляет стабильные eventId/sequence/memberId только уже наступившим событиям. Native использует общий задержанный clock для маршрута, клипа, снаряда, реакции и визуального HP. Начальное окно 1650 мс, дальнейшая оценка p95 интервала ответов + 760 мс подготовки, предел 4500 мс; окно фиксируется на бой, время не идёт назад. Локальные 20 HTTP-измерений: p95 интервала снимков 857 мс, RTT p95 58.8 мс; 857+760=1617, округлено вверх. Это не мобильная сеть. Позднее событие учитывается без повторного диагностического контакта; холодный вход не проигрывает старую последовательность заново. Снаряд выпускается за 260 мс до контакта; начало Attack за 760 мс соответствует выпуску на 0.50 с текущего клипа. Различаются длины стрелы, болта и дротика; исходная точка берётся с существующей кисти. Точный muzzle арбалета, тетива, хват и все размеры целей ещё не приняты.
До: R16/R17/R18 при contact−200 мс не было снарядов. После: 5/4/1 видимых снарядов соответственно. Это три последовательности остановленных render-состояний с доставленными к этому моменту буфера событиями, не запись 20 плавных выстрелов. 20 выпусков/контактов × 3 типа × 3 cadence прошли только логическую проверку clock. Аудиосинхронность и допуск в один отрисованный кадр OPEN. Веб-очередь имеет нулевую добавочную задержку: перенос native-буфера без переноса оружейных маркеров создал бы новый рассинхрон; веб D01 не объявляется исправленным.

D02 — исходная ошибка воспроизведена, исправление проверено на R01 и логических сценариях; полная приёмка OPEN.
До: погибшие ENG-01_0..2; затем _0 и _1 снова Run. После: возвращаются исходные ENG-01_3 и _4 с прежними instance ID. В серверном хвосте сохраняются исходные индексы, включая холодный вход; Death длится 1.2 с, тело отделено от сбора выживших и ограничено пулом 24. Последние события полного поражения сохраняются 8 с после мгновенного возврата; native даёт смерти закончиться. Добавлены проверки переключения карты, ограниченного хвоста и удаления кэшей. Полный онлайн reconnect/фон приложения/все составы на iOS и отдельная веб-идентичность OPEN.

D03 — воспроизводится, НЕ исправлен.
Повторное измерение настоящих GLB совпало с gait_table. ENG-05: маршрут 8 ед/с, опорная скорость при предельном tempo 1.6 — 2.69468, дефицит 66.3165%. ENG-06: 7 против 2.69468, дефицит 61.5046%. Метод: 60 выборок bone foot/toe/hoof за цикл, опора около минимума высоты, масштаб поля 1.15. Это костные пробы, не измерение подошвы skinned mesh. Скорости маршрута и темп ног не увеличивались ради маскировки.
Нужен новый быстрый цикл для существующих ENG-05/ENG-06; имя нового ресурса не выдумано. Приёмка ресурса: штатные 7/8 ед/с, измерение мирового смещения копыта в опоре, целевой остаток не более 5% скорости корня и отсутствие видимого скольжения; отдельные старт/стоп/поворот. Проверить таз/седло, ноги/стремена, обе руки/оружие во всех фазах и на склонах. Ограниченная коррекция шага допустима лишь после измерения нового цикла; текущий разрыв не покрывается небольшой коррекцией.

D04 — подтверждён частично; исправления выбора позиций НЕТ.
Добавлен opt-in overlay footprint, нормалей и высот грунта, костных проб опор, занятых AABB и AABB обычных зданий. Включение: --combat-debug или «Опоры» в лаборатории. AABB консервативны, костные начала не равны контактной поверхности; world Multimesh-препятствия ещё не покрыты. Это диагностика, не доказательство пересечения треугольников. Алгоритм battle_place пока проверяет сухой грунт, а не свободный объём/уклон/последний подход. Нужна отдельная реализация с проверкой препятствий и полного footprint. S14/S15 остаются открытыми.

D05 — локальное исправление читаемости проверено; устройство OPEN.
Числа размещаются в экранных координатах с учётом stretch, охраняют прямоугольник контакта 76×60 пикселей и не пересекаются между собой. Пул 10. Объединяется только один target, вид события и точный авторитетный tick; сумма и список event ID сохранены, финальный удар отдельно с первым приоритетом. Веб-урон бойцу группируется по memberId, а не по ID животного. При нехватке места низкоприоритетная подпись не рисуется; результат сервера не меняется. На S14/S15 читаемость показана исходными кадрами до/после. Полная матрица массовых боёв и проверка safe-area для подписей на iPhone OPEN.

D06 — исходное перекрытие и потеря первого касания воспроизведены; компонентный тест после изменения PASS.
Единый modal ownership делает фон inert, убирает нижнюю навигацию, ограничивает высоту по visualViewport/safe-area, сохраняет footer, возвращает фокус. Количество обновляется при input; неизменившийся состав не запускает новый preview при blur. До: центр «Марш» попадал в «Цели»; после исправления слоя обнаружен второй дефект: touchstart/end были, click исчезал из-за повторного preview на blur. После обеих правок: один tap → одна deploy-команда, tap «Продолжить» возвращает панель и управление. Высоты 390 и 320 при ширине 844 прошли hit-test. Это Chromium с настоящими touch-событиями и реальными online.mjs/API-обработчиками, но без 3D-рендера в компонентном стенде. Переход к цели задаётся fixture-событием. Полный веб-прогон с 3D получил timeout открытия охоты; Safari/iOS keyboard/safe-area и native-модалы OPEN.

D07 — пакетная потеря событий воспроизведена и устранена в веб-компоненте; визуальная приёмка OPEN.
До: 14 событий давали два FX и последнее состояние Attack. После: все 14 ID обработаны по времени, пять совместимых групп FX сохраняют принадлежность и суммы. Native уже отдавал Attack приоритет над Hit — это решение не переписано. Настоящая аддитивная реакция тела не добавлена; животные всех размеров и выбранные ими цели ещё требуют визуального прогона.

КАК ПРОВЕРИТЬ
IPA — неподписанная автономная лаборатория, новый bundle com.drenovar.game.combatlab, отдельная установка через принятый владельцем способ переподписи. Никакого сервера/аккаунта. Показывает настоящие сцены и код представления на синтетических записях; кнопки следующий/предыдущий/пауза/опоры. Это НЕ обновление опубликованного приложения и НЕ приёмка сетевого клиента.
PCK — запуск Godot 4.6.3: godot --main-pack DRENOVAR-combat-1008.pck. На Linux без GPU можно указать --rendering-method gl_compatibility; этот режим не равен iOS Metal.
Веб-архив — распаковать, установить Node 24.22.1, выполнить node v6/local-server.mjs, открыть http://127.0.0.1:8786/. По умолчанию локальная SQLite и новое тестовое поселение. Для физического Safari нужен отдельный согласованный HTTPS-стенд; он не опубликован.
Весь первоначальный код main.tscn сохранён в ветке. Feature combat_lab переключает только тестовый экспорт в автономную лабораторию. Для интеграционного сетевого теста использовать main.tscn из checkout с --server=http://127.0.0.1:8796 --hosted и локальным fixture-адаптером.
