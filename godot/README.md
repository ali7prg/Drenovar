# DRENOVAR для iOS

Нативный порт на Godot 4.6.3. Сборка использует Metal на iOS и ландшафтную ориентацию. Референс для 0.4.0 — веб-версия 90, коммит `6707b03342456b1d9762978462a860ec06d39cd4`. Готовые GLB и текстуры копируются побайтно. Рельеф, модели окружения и их размещение генерируются из исходных функций.

В 0.4.1 карта использует оригинальные изображения дальних поселений и крон из веб-версии. При приближении поселения возвращаются к исходным 3D-моделям. Замер на карте показывает расстояние камеры и количество объектов в каждом режиме отрисовки.

В 0.4.2 окно похода показывает ожидание ответа и сохраняет выбранных воинов для повторного расчёта после тайм-аута.

В 0.5.0 перенесены каталог общего мира с городами, целями охоты и походами, поворот карты, центрирование города, атлас окружения, запасы и пассивный доход, выбор участка и сведения о строительстве, ступени армии, подтверждение отмены найма и состав отряда с быстрым выбором и возвратом из расчёта маршрута. В доступных ступенях и целях действуют ограничения общего сервера.

В 0.5.1 у ресурсов появились отдельные карточки и иллюстрированные значки, а окна получили новую тему. Панель запасов показывает точный баланс и отдельно отмечает остановку производства при достижении предела. Камера следует за центром жеста масштабирования. Город использует исходные варианты моделей деревьев по расстоянию, один проход каскадных теней и текстуры грунта с мип-уровнями. Диагностика содержит отдельный замер кадров при движении камеры.

## Обновление 0.5.2 (тестовая сборка, 11 ноября 2026)

Ручное движение камеры использует проекцию касаний на плоскость карты без
догоняющей интерполяции. Панорамирование и масштабирование удерживают точку
под жестом. Пересчёт видимых объектов остаётся в кадровом цикле, а не выполняется
на каждый приходящий touch event. Автоматические перелёты сохраняют сглаживание.

Ресурсные карточки заменены общей тонкой полосой: значок и число без цветных
рамок. Навигация перенесена вниз вправо; кнопки и окна получили более строгие
контуры и сине-серые поверхности. Это приближение к компоновке видеореференсов,
а не подтверждённое попиксельное совпадение с Viking Rise.

В городе для почвы и камня используются их отдельные normal/roughness-карты.
У материалов 3D-моделей включена анизотропная фильтрация с mipmaps.
Исходные текстуры, модели, размещения, ограничения детализации и тени сохранены.
Новые 3D-модели в этой версии не создавались.

Проверка: `godot --headless --path project -s qa_camera_hud.gd`.
153 проверки: проекция жестов, отпускание/отмена, модальные окна, размеры HUD,
поведение запасов выше/ниже производственного предела. Импорт/экспорт и запуск
игрового PCK проверены Godot 4.6.3. Нет проверки Metal, скриншотов нового
нативного интерфейса, замера FPS/нагрева/памяти на физическом iPhone.

Тестовый IPA содержит неизменённый arm64-бинарник Godot из 0.5.1 и новый
экспортированный PCK. Новая компиляция Xcode не проводилась. IPA не подписан;
для установки нужна подпись через уже используемый способ тестовой установки.
Версия 0.5.2 не опубликована в App Store или TestFlight.

## Текущий объём

- Трёхмерные город и карта, панорамирование, масштаб и выбор объектов.
- Четыре стартовые постройки, рельеф, лес, поселения, дороги и водная поверхность. На мировой карте размещено 11 107 объектов из генератора веб-версии. Используются ближняя и дальняя геометрия, материалы травы, грунта, камня и снега, миникарта и переключатели слоёв.
- Сглаживание камеры и сохранение ракурса города и карты. Недавно открытая сцена переиспользуется при быстром возврате и освобождается через четыре секунды простоя или при предупреждении о памяти.
- Вход в существующий аккаунт через подтверждение в браузере и подключение к общему серверу игры. Нативная сессия хранится в оперативной памяти приложения.
- Расчистка рощ и участков, строительство, улучшения, стартовые цели, рынок, гарнизон, лазарет, очереди обучения и ускорители. У казарм видна модель обучаемого воина. Прогресс хранит общий сервер.
- Переселение, смена имени и названия поселения, карта с восстановлением полного обзора, расчёт маршрута, отправка походов и подробные боевые отчёты.
- Городские рабочие, детали улучшений, строительные леса, подлесок и пни на месте срубленных деревьев. Парадный строй отображает состав гарнизона.
- Модели пехоты, конницы и стрелков идут строем по маршруту. Анимации ударов, попаданий, падений и выстрелов привязаны к событиям охоты от общего сервера. Клиент показывает серверные потери и награды в отчётах.
- Город и мировая карта разбиты на 64 участка рельефа каждый. Нормали, текстурные координаты и цвета на границах совпадают. Замер кадра ведётся по отдельности для каждой открытой сцены.
- iOS-сборка использует ранее собранный нативный бинарник Godot 4.6.3 с новым пакетом игровых ресурсов. Плавность, кадрирование интерфейса и работа Metal проверяются на физическом iPhone.

## Воспроизведение проверки

С пакетными ресурсами откройте проект `project/project.godot` в Godot 4.6.3. Для проверки сетевого пути в отдельном тестовом мире нужен исходный каталог веб-сервера DRENOVAR и Node.js 24.

```bash
node tools/test-realm.mjs /path/to/web-v90
godot --headless --path project -- --server=http://127.0.0.1:8417 --smoke
```

Чтобы воспроизвести тайм-аут первого расчёта городского похода, задайте `DRENOVAR_TEST_CITY_PREVIEW_TIMEOUT=1` для обеих команд.

Если в проекте отсутствует `project/assets`, подготовьте ресурсы из опубликованных исходных файлов.

```bash
node tools/fetch-web84-assets.mjs build/web84
node tools/import-web-assets.mjs build/web84
```

## Сборка для устройства

`tools/package-ios.sh` экспортирует проект Xcode. На macOS с Xcode он компилирует его в неподписанный пакет `DRENOVAR-unsigned.ipa`. Пакет нужно подписать при тестовой установке на устройство.

```bash
python3 tools/ios-template.py "$HOME/Library/Application Support/Godot/export_templates/4.6.3.stable/ios.zip"
bash tools/package-ios.sh build/ios
```

Задание GitHub Actions в `.github/workflows/drenovar-ios.yml` рассчитано на приватный репозиторий с исходниками в каталоге `native-ios`. Задание запускается при обновлении исходников ветки `native-ios-godot`.
