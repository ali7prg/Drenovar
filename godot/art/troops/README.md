# DRENOVAR English soldiers — reproducible build pipeline (0.6.0)

All ten English units (ENG-01 … ENG-10) are generated by these scripts with
Blender 5.3 used as a Python module. The output is what the game loads from
`godot/project/assets/army/troops06/` (`ENG-xx-lod1.gltf` = preview,
`ENG-xx-lod2.gltf` = field), wired through `assets/game.json → unitModels`.

## Sources and licences

| Input | Origin | Licence |
|---|---|---|
| Human base mesh `hm08`, macro targets (age, muscle, weight, height, proportions), default skeleton and skin weights, low-poly eyes and `brown_eye.png` | MakeHuman 1.x repository, `makehuman/data/…` (github.com/makehumancommunity/makehuman) | **CC0 1.0** (`LICENSE.ASSETS.md` of that repository) |
| Horse body, mane, tack, saddle, caparison, horse rig and horse animations (ENG-05/06) | DRENOVAR 0.5.9 project assets `assets/army/assets/ENG-05-scout-lod1.glb`, `ENG-06-knight-lod1.glb` | DRENOVAR project |
| Everything else: garments, armour, helmets, weapons, shields, all textures, all soldier animations | Generated by the scripts in this folder | DRENOVAR project |

No third-party texture, model or animation library is used. The MakeHuman
skin shader is not used; skin, cloth, mail, leather, steel and wood textures
are procedurally baked (`texbake.py`, `patterns.py`, `materials.py`).

## Files

| Script | Purpose |
|---|---|
| `mh_base.py` | Builds the body from `base.obj` + macro targets; 67-bone game skeleton (spine, neck, head, clavicles, upper-arm/forearm twist bones, 15 finger bones per hand, legs, toes); CC0 weights remapped onto kept bones |
| `gear.py` | Garment shells (offset body regions that inherit the skin weights), skirts, belts, straps, helmets, plate pieces, spear, sword, longbow, crossbow, javelin, kite and round shields, hand-grip frames |
| `layers.py` | Outfit layers used by the unit definitions |
| `texbake.py`, `patterns.py`, `materials.py` | UV-space texture baking from rest-pose 3D patterns; tiling steel/wood/leather/rope textures; PBR materials |
| `anim.py` | Forward kinematics over rest matrices + analytic two-bone IK; planted-foot gait generator; clip keying |
| `poses.py` | Combat styles: spear+shield, sword+shield, longbow, crossbow, javelin+round shield; Idle, Walk, Run, Attack, Hit, Death, Shield_Block and the drill clip from `game.json` |
| `mounted.py` | Mounted units: keeps the project horse, removes the old rider, seats the new rider (root parented to `HorseBack`), solves stirrups, reins and weapon for every horse clip |
| `build.py` | Unit definitions (one function per unit), body-hiding under opaque garments, export of `.blend`, LOD1 and LOD2 glTF |
| `compress_textures.py` | Converts exported textures to baseline JPEG that Godot 4.6.3 imports |

## Rebuild one unit

```bash
python3 -m venv .venv && .venv/bin/pip install bpy==5.3.0 pillow numpy
git clone --depth 1 --filter=blob:none --sparse https://github.com/makehumancommunity/makehuman /tmp/mh
(cd /tmp/mh && git sparse-checkout set makehuman/data/3dobjs makehuman/data/rigs \
   makehuman/data/targets/macrodetails makehuman/data/eyes)
export MAKEHUMAN_DATA=/tmp/mh/makehuman/data
.venv/bin/python -I godot/art/troops/build.py -- --unit ENG-01 --out /tmp/eng01 --blend godot/art/troops/blend
python3 godot/art/troops/compress_textures.py /tmp/eng01 90
cp /tmp/eng01/ENG-01-lod?.gltf /tmp/eng01/ENG-01-lod?.bin godot/project/assets/army/troops06/
cp -r /tmp/eng01/ENG-01-textures godot/project/assets/army/troops06/
```

Then in `godot/project`: `godot --headless --import --path .`,
`godot --headless --path . -s profile_gait.gd` (re-measures stride speeds into
`src/gait_table.gd`) and the checks `qa_troops06.gd`, `qa_warriors.gd`,
`qa_gait.gd`.

## Editable sources

`blend/ENG-xx.blend` is each unit's complete scene (rig, meshes, materials,
all actions) saved by the build. The scripts remain the source of truth: a
change should be made in the unit function and rebuilt, so that LODs,
textures, gait table and checks stay consistent.

## Budgets enforced

* Field LOD (`-lod2`) is decimated to the triangle count of the 0.5.9 field
  model it replaces (`FIELD_BUDGET` in `build.py`, checked by `qa_troops06.gd`).
* Baked maps are 1024 px for skin, aketon, surcoat and mail and 512 px for
  smaller parts; tiling maps are 512 px.
