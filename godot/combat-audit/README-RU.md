# DRENOVAR Combat 1009 — проверяемая тестовая реализация

Релиз предназначен для проверки изменений. Полная приёмка аудита остаётся открытой, прежде всего физический iPhone 12, геометрия раннего подхода и часть оружейных клипов. Лаборатория автономна: реальные игроки, поселения и production не используются.

## Комплект и версии

Получены все 34 части, восстановлен архив 270109805 байт, SHA-256 `75cccc1226ec0921840f258f75a69a605510997445e5ebc25ea5bb4b51ee8129`. Распакованы 439 файлов; 438 записей манифеста и сам манифест. Результаты проверки находятся в evidence. Прочитаны START-HERE, HTML/PDF, defects, developer-spec, retest и PROMPT-DEVELOPER; оригинальные материалы сопоставлялись с текущим кодом.

Аудит относился к iOS 1005 (`2389001`), Site96 (`3ff0d105`), API `e5062aa`. Нативная база изменений — 1007 (`c91e83a`), серверная база — V6 `025e7af`; старый v92 не подменён новым solver. Разные GLB веба и glTF Godot исследованы отдельно. Запросы внешних version endpoints дали HTTP 403: текущую live-выкладку независимо подтвердить не удалось. Точная версия опубликованного пакета — коммит его release; версия экономики C1.0, API6 и схема6 сохраняются. Исторический v6/versions.json не изменяет production-пару.

## Проверка и ограничения

63/63 серверных и веб-проверок; 67/67 одинаковых исходов до/после (урон, события, HP, длительности, travelMs, награды, погибшие/раненые/выжившие/возврат); 32 локальные HTTP проверки; исходные v92 тесты, миграции и SHA-256 исходников. Native: 32 clock/ID, 50 city, 22 world, 156 gait checks, отдельный audio-pool test и 100 последовательных аддитивных реакций без накопления позы. Повторная проверка опор/объёмов — 87/87 мест, включая три городских состава. Упакованный PCK загружается, содержит 21 модель (20 soldier LOD + ram) и 162 здания VI–XI. Полные журналы — evidence.

60 сочетаний 10 воинов × 2 вида целей × 3 размера присутствуют в лаборатории и проходят отдельный отрисованный replay. Снимок contact+200 мс — только покадровая проверка; он не доказывает плавность полного боя. Дополнительно выполнены десять последовательных боёв при настенных часах 1×. Исходный Linux использует Mesa llvmpipe, 844×390, программный OpenGL, Dummy audio; часть прогонов шла одновременно с проверками браузера. Время кадра порядка сотен миллисекунд/секунды — непригодно для визуальной приёмки, не оценка производительности iPhone. Численные измерения и контекст конкурирующей нагрузки в performance.json. Ресурсы не упрощались ради FPS.

Ни одна фотография, схема движения или stopped replay не названа доказательством полной работоспособности на iPhone. Физического iPhone12, Xcode/macOS и реального аудиовыхода в этой среде нет. Native test IPA использует исходный проверенный engine capsule; требуется установка/подпись через SideStore/AltStore и проверка владельцем отдельно от web/Safari.

## Конкретные оставшиеся задачи на ресурсы

1. Глобальный подход: уклон/перепад и footprint должны проверяться по всему пути колонки, включая отступление; провести S14/S15 без красных сегментов и без резервного ближнего бойца, которому сервер назначил попадание. Не исправлять это телепортом/изменением travelMs. Сложные карты требуют решения в общей навигации.
2. Sword_Drill ENG-07/08/09 и часть mounted Attack имеют учебное движение, не гарантированную траекторию по реальному объёму цели. Нужны клипы подготовки/контакта/восстановления в существующем риге; конец оружия пересекает заданный объём цели, не землю/соседей; хват/седло/стремена сохраняются. Источник, кадры sourceTime и 30 сравнительных поз опубликованы.
3. Физический iPhone12 landscape: отдельно Godot/iOS и Safari, десять последовательных онлайн-боёв, все типы/уровни, поздние пакеты, reconnect/фон, победа/поражение/доступное отступление; кадр/FPS/память/объекты и AV-синхронность. Число успешных N/M фиксировать по каждому критерию, не по числу запущенных тестов.
