# DRENOVAR V6 — приложение общего сервера

Сборка1004, версия0.6.0, предназначена для подключения приложения и сайта к одному сохранению основного города. Адрес API: https://drenovar-game.ali069587.workers.dev. Веб-адрес сохраняется: https://drenovar.pink-lyric-9420.chatgpt.site. Экономика C1.0, API6, JSON schema6. Фактическое завершение переноса фиксируется отдельно в серверном отчёте; один IPA не мигрирует базу.

Название под иконкой — DRENOVAR. Сохраняется bundle `com.drenovar.game.v6test`, чтобы обновление сборки1003 оставило сессию устройства. После смены сервера прежний тестовый кэш не показывается как основной город: кэш привязан к адресу API. В отсутствие подтверждённого города приложение сразу открывает экран аккаунта. Создание нового города на основном сервере отключено.

## Обычный вход

1. Открыть сайт DRENOVAR и войти в тот же аккаунт ChatGPT, которому принадлежит основной город.
2. Нажать «Открыть основной город». Сервер проверит владельца и подключит уже существующее сохранение, сохраняя его ID, уровни, размещение и прогресс. Это не загрузка новой копии с телефона.
3. В веб-разделе «Аккаунт» получить код подключения. Код одноразовый и действует10 минут.
4. В приложении открыть «Аккаунт», подключить устройство и ввести код. Откроется тот же город. После этого приложение и браузер используют один сервер; отдельной трансляции и периодического копирования нет.

Код и секрет устройства не прикладывать к отчётам. Повторный вход не выдаёт новый город или повторные награды. Основной аккаунт не назначается первому посетителю сайта: проверка старого входа обязательна. На Cloudflare не доверяют заголовкам идентичности браузера. Проверку ChatGPT выполняет существующий Sites origin.

## Проверка

`qa_shared_main.gd` и браузерная проверка открывают подготовленный существующий аккаунт, привязывают второй клиент, начинают заказ в приложении, отменяют его через браузер и проверяют итог в приложении.17 проверок прошли на Linux с настоящим Godot и браузером. Это не физический iPhone. `qa_primary_account_screen.gd` проверяет начальный экран основного подключения без создания города и без сетевой записи; `qa_session_server.gd` — шифрованный кэш и разделение серверов. Прежний тестовый аккаунт отдельно проверяется `qa_v6_account.gd` с явным local/staging `--server`.

На iPhone12 landscape: проверить имя/номер1004, вход в основной город, совпадение ресурсов/очередей с браузером, закрытие и повторное открытие приложения, разрыв сети после команды, город↔карта10 раз. Не начинать новое поселение ради доступа. Физические FPS/нагрев/устойчивость остаются отдельным измерением.
