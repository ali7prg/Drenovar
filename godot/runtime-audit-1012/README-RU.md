# Исправление реальной охоты внутри поселения — 1012

Репродукция: оригинальный опубликованный PCK 1011 + точный сервер e5062aa, синтетический город, 45 бойцов (20 ENG-01, 20 ENG-03, 5 ENG-05), Тенерис I. Клип Attack ни разу не включается; контроль прошёл все проверки кроме анимации (25/26). Основной режим main.tscn, реальная авторизация устройства и HTTP; не Combat Lab.

Изменения клиента: обновление кэша событий при переходе outbound → fighting, даже если пакет событий не изменился; HTTP 5xx отделён от отказа транспорта, HTML-страница сохраняет httpStatus; ограниченные повторы команды сохраняют Idempotency-Key. Ошибка сервера больше не показывается как «Нет сети». Серверная пара обязана сохранять историю уже завершённых коротких боёв; готовый патч также ускоряет поиск пути без изменения пути/travelMs.

После: 197/197 проверок, 10/10 последовательных охот на Тенерисов I–III с Attack, результатом, Continue, возвратом и повторным входом. В первой команде два 503 уже после записи результата: 12 HTTP-попыток = ровно 10 разных команд. В отдельной проверке HTML 503 → 200 правильная диагностика и восстановление, 10/10 проверок. Все 6 применимых Godot-наборов прошли.

Визуальная проверка обычной игры: Linux, Godot 4.6.3, программный OpenGL/llvmpipe, 844×390; 2 охоты, 45/45 проверок, последовательные attack-кадры и запись actual UI. Это медленный тестовый рендер, не FPS iPhone и не Metal-приёмка. Часы ускоряют лишь дорогу и возрождение; бой работает по реальному времени. В продукте качество ресурсов, освещения и рендерер не снижались.
