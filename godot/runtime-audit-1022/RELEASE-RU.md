Игровая сборка 1022 (0.6.0): тестовая. Линия 1021 и лесное приключение «Лес потерянных» в одной сборке.

Сборка не проверялась на iPhone. Всё проверено на Linux (Godot 4.6.3) в настоящей сцене игры и на локальном синтетическом сервере V6.

- Вся 1021 сохранена: город, бои, походы, звери (creatures v2), сеть и запуск.
- Лес вокруг города принадлежит лесному слою приключения: деревья, подлесок, туман войны. Пока сервер не включил приключение, лес закрыт туманом, ошибок и лишних запросов нет.
- Сборка леса при загрузке города идёт по кадрам, срубленное дерево убирается без пересборки всего леса.

Установка поверх обычной DRENOVAR через SideStore, Bundle ID `com.drenovar.game.v6test`.
