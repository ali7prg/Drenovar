обновлялся, действующая игра и данные игроков не менялись.

## Основа

- Патч сделан к оригинальному серверу v92, коммит `365276cc169943adc48847c0e9d86ae23e77fb3e`.
- Применяется к чистому v92 и вместе с патчем speedups-v2 в любом порядке

  `2899bced13d6b052c791ef13add5e10ec5f31088c5b5c4e4eba9f4ad8e5ab25c`.

## Что добавляет патч

1. **Перенос здания** в новом поселении: `{kind:"kingdom", action:"move", buildingId, plotId}`.
   В поселении старого типа: `{kind:"legacyBuilding", action:"move", buildingId, plotId}`.
2. Перенос бесплатный, без строителя и таймера. Здание сохраняет id, тип, уровень, очереди
   обучения и производство; меняется только `plotId`.
3. Отказ, если: здание не найдено; участок тот же, занят, неизвестен, не расчищен или в лесу;
   слишком близко к другому зданию; участок на базе войск; строитель работает над этим
   зданием или на целевом участке. Проверки участка те же, что у стройки
   (`constructionPlotProblem`), без учёта самого переносимого здания.
4. **Уникальные id новых зданий.** Новое здание получает id `building-<участок>`. Если на
   старый участок перенесённого здания ставят новое, id нумеруется (`building-v1-1-2`).
   Изменены `kingdomCommand` (build) и `placeBuilding` (legacy).
5. **Признак для клиента:** ответы `state` и `command` содержат `cityFeatures:["moveBuilding"]`
   (добавляется в `hosted.mjs`). Клиент включает перенос только при этом признаке.
6. Повтор команды с тем же `Idempotency-Key` возвращает тот же ответ (обычный механизм v92).

  участок, неизвестное здание, здание на улучшении), ресурсы не списаны, повтор тем же ключом,
  перенос обратно, уникальный id новой постройки на старом участке, перенос ратуши.
- Без изменений проходят тесты v92: closed-cycle61, economy62, upgrades-v1, hosted,
  native-session, world62, paid-training92, accounts40, founder42, server.
- Клиент: `qa_move_building.gd` против `test-realm.mjs` с патчем — 14 проверок без ошибок.

## Не входит в патч

- Бонусы стен и сторожевой башни в бою (`cityFeatures: cityDefence`). Клиент показывает их
  по таблице `godot/project/src/city_defence.gd` и пишет, что в бою v92 считает только
  гарнизон. Чтобы бонусы действовали, нужно изменить `duel62` на сервере — отдельное решение.
