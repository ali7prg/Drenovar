# Серверный патч route-approach-v1 к DRENOVAR Server v92

**Статус: не развёрнут.** Предложение к оригинальному серверу v92. Production не обновлялся,
данные игроков не менялись.

## Ошибка

При атаке на зверя в городе сервер отвечает «Нет безопасного пути к цели» и на расчёт маршрута
(`march-preview`), и на сам приказ (`deploy`). У игрока атака на этого зверя не проходит никогда
или большую часть времени.

## Точная причина

`gameplay37/server/navigation.mjs`, `cityRoute()`:

1. Маршрут строится A* по сетке с шагом 2 от `home` (0,16) до клетки зверя, округлённой до сетки.
   Каждая клетка проходит `validCityPoint()`: внутри карты, `plantable` (не вода и не крутой склон)
   и **не ближе 5 м (по каждой оси) к любой постройке**.
2. Поиск считается успешным, только если из очереди достаётся сама клетка цели. Клетка цели
   попадает в очередь только через ту же `validCityPoint()`.
3. Патруль зверя (`patrol()` в `core.mjs`) задаётся один раз при появлении. Тогда действует запас
   12 м от построек (`spawn:true`). Позже строительство зверей не учитывает. Пример: участок
   `v1-33` (-38,-40) открыт уже на ратуше I, на ратуше II на нём можно строить.
4. Постройка на `v1-33` оказывается в 2 м от патруля Тенериса I (-44..-40, -44..-40). Две из пяти
   точек патруля и все клетки между ними попадают в 5-метровую зону постройки. Пока зверь там
   (11 из 20 секунд цикла), клетка цели недопустима, и `cityRoute()` обходит всю карту и бросает
   ошибку. Предпросмотр и приказ вызывают одну и ту же функцию, поэтому отказывают оба.

Что **не** является причиной (проверено):

- **Начальная точка.** `home` остаётся связной с картой при любой постройке на любом участке
  деревни. Проверены все одиночные участки и все пары.
- **Вода.** На пустой карте достижима каждая допустимая клетка, переправа (`ferryLanding`)
  работает.
- **Алгоритм поиска.** Для всех 4280 целей, достижимых в v92, путь тот же байт в байт.

## Исправление

В `navigation.mjs` поиск вынесен в `searchCityRoute()`, а `cityRoute()` использует его так:

1. Если клетка зверя допустима, работает прежний поиск без изменений (тот же порядок, та же
   эвристика, тот же результат).
2. Если клетка недопустима или прежний поиск не нашёл пути, ищется ближайшая к зверю
   **допустимая** клетка не дальше `APPROACH` = 8 м. От неё последний шаг идёт прямо к зверю, только
   по земле `plantable` и в пределах карты. Шаг разбит на отрезки не длиннее 2 м, поэтому
   `routeUsesFerry()` не принимает его за паром.
3. Если такой клетки нет, остаётся прежний отказ «Нет безопасного пути к цели».

Проверки безопасности не отключены. Все клетки сетки на маршруте проходят ту же
`validCityPoint()`. Вода, края карты и обрывы по-прежнему дают отказ. Ослаблен только последний шаг
не длиннее 8 м: отряд подходит к зверю, который сам стоит у постройки. Механика, экономика, бой,
награды, сохранения и формат ответа (`path`, `travelMs`, `usesFerry`) не менялись. Бой происходит
там же, где стоит зверь (`path.at(-1)`), как и раньше.

## Стенд

`godot/tools/test-realm.mjs` с `DRENOVAR_TEST_BLOCKED_CREATURE=1` создаёт постройку на `v1-33`,
ставит Тенериса I в точку (-40,-40) и останавливает часы. Флаг работает только в изолированном
loopback-мире.

```
DRENOVAR_TEST_BLOCKED_CREATURE=1 node godot/tools/test-realm.mjs <путь к серверу>
cd godot/project
DRENOVAR_QA_EXPECT_REFUSAL=1 godot --headless --path . -s qa_march_refusal.gd -- --server=http://127.0.0.1:8417   # сервер без патча
godot --headless --path . -s qa_march_refusal.gd -- --server=http://127.0.0.1:8417                                # сервер с патчем
```

## Развёртывание (после согласования, не в production напрямую)

1. Сверить действующую версию сайта с v92 (`365276cc…`). Если версия новее, переносить патч на неё.
2. В отдельной копии: `git apply route-approach-v1.patch`, затем
   `node gameplay37/tests/route-approach.mjs` и `python3 tools/run_original_tests.py`.
3. Собрать hosted (`hosting37`: `pnpm install --frozen-lockfile`, `npm run build`) и развернуть на
   **отдельный тестовый адрес с отдельной базой**. Проверить атаку на зверя у постройки с телефона.
4. Только после этого переносить в production. Миграция данных не нужна: патруль, позиции и
   сохранения не меняются, меняется только расчёт маршрута. Откат — вернуть прежний
   `navigation.mjs`.

## Клиент

Сервер с патчем работает и с прежними клиентами. Отдельная клиентская правка
(`godot/project/src/main.gd`, окно «Создать войско»): если «Марш» нажат до расчёта маршрута и сервер
отказал, клиент показывает причину вместо вечного «Прокладываем путь…» и предлагает «Повторить
расчёт».
