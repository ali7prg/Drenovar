# Серверный патч story-quests-v1 (главы ратуши I–V) к DRENOVAR Server V6

**Статус: подготовлен и проверен локально, на боевой сервер не установлен.**
Отправка в частный репозиторий сервера из этой сессии не разрешена, поэтому файл патча передан
владельцу отдельно. Установка на боевой Worker требует отдельного подтверждения владельца.

## Что это

Журнал заданий клиента 1025 (`godot/project/src/story/story_flow.gd`): пять глав по уровням ратуши,
у каждой цели есть действие, счётчик и точная награда. Выполнение проверяет сервер, награду
зачисляет только команда Claim, и зачисление происходит один раз.

- Новый модуль `v6/story-quests.mjs`: главы, цели, `storyView(p)`, `storyCommand(p, body, now)`.
- `v6/game.mjs`: в проекции добавлено `v6.story`, а в очереди квитанций — команда `story72`
  (тем же путём, что `starter71`: Idempotency-Key, повтор после обрыва возвращает то же состояние,
  а изменённое тело с тем же ключом получает 409 IDEMPOTENCY_CHANGED).
- Тест `v6/tests/story-quests.test.mjs`.

## Контракт

Проекция `state.v6.story`:

```
{version: 1, hall, chapter, current: {chapter, goal} | null,
 chapters: [{id, hall, title, who, unlocked, claimed, total,
             goals: [{id, kind, title, action, helps, go, have, need,
                      state: 'active'|'ready'|'waiting'|'claimed'|'locked',
                      reward: {food, wood, stone, iron, coins}, waitsFor?}]}],
 scenes: {intro?: ms, chapter2_talk?: ms}}
```

Команды `{kind: 'story72', ...}`:

| action | тело | правило |
|---|---|---|
| `claim` | `goalId` | глава открыта (иначе 409 «This chapter opens with Town Hall …»); цель выполнена (иначе 409 «Finish the goal first»); повторный Claim ничего не делает |
| `visit` | `target: 'B01'` | отметка о нажатии на ратушу (цель главы I) |
| `seen` | `scene: 'intro' \| 'chapter2_talk'` | сцена показана, повторно её не показывают |

Награда идёт через квитанцию `story:<goalId>` (`grantReward` и `claim` V6). Цели First Steps
(`starter:wood|train|hall|build|hunt`) остаются в журнале со своим прогрессом и выдаются прежней
квитанцией First Steps по прежнему порядку. Готовые награды хранятся в `p.story72`: они остаются
готовыми между входами и после повышения ратуши.

## Главы

| глава | ратуша | цели (награда) |
|---|---|---|
| I Take In the Fugitive | I | нажать на ратушу (100 еды, 50 дерева); First Steps: дерево; срубить дерево (120 дерева, 20 монет); First Steps: обучение; First Steps: ратуша II |
| II Ready the Squad | II | обучить 10 бойцов; First Steps: стройка; амбар B04; склад B03; ферма B09 II; First Steps: охота; ратуша III |
| III Back for the Prisoners | III | лес открыт; Берёзовая просека найдена (шаг 1); печать (шаг 2); страж (шаг 3); клетка (шаг 4); пленники дома (шаг 5); B02; ратуша IV |
| IV The Next Expedition | IV | участок 02 до конца; 40 бойцов; амбар III; участок 03 до конца; B08 III; ратуша V |
| V Bring the Expedition Home | V | лазарет B16 II; участки 04–06 до конца; 120 бойцов; 18 спасённых (итог второго акта) |

Числа сверены с ценами и складом из `balance`: ни одна награда не превышает вместимость
склада своего уровня ратуши (2000 / 3000 / 5000 / 10000 / 25000 на ресурс).
